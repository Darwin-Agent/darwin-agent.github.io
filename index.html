Our thesis

Experience should compound.
Action should improve.

Completing a task is not the end of learning. Our goal is to preserve what an agent discovers, make that experience useful in the next action, and turn outcomes into evidence for improvement.

We study the mechanisms that close this loop: memory that carries experience forward, harnesses that turn knowledge into behavior, world models that inform action, and feedback that guides evaluated changes.

Our unit of evolution is not only the model.

It is the entire agent system.

Our identity

D surrounds A.
A reaches outward.

A shared mark for one evolving system. The enclosing D represents accumulated experience; the outward-reaching A represents action. Feedback brings action back into learning.

Accumulation & feedback

D — Darwin

A stable vertical spine and an enclosing arc express continuity: experience is retained, memory is built, and learning carries forward.

Action & evolution

A — Agent

The A extends from within the D. Its pointed apex and angled strokes give the mark an upward, forward direction: accumulated experience becomes action.

Connection & clarity

Two letters. One system.

A shared connection links learning and action. Clear negative space keeps D and A separately recognizable, without separating them into independent systems.

A system built

Experience becomes useful when it changes what an agent does next. We study how instructions, skills, tools, memory, world models, and interaction topology can be updated from feedback. Proposed changes must be evaluated before adoption, so the next cycle builds on evidence rather than repetition.
